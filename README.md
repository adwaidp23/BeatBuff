# Beatbuff

## Project Overview
**BeatBuff** is a gesture-controlled music player that uses a webcam and computer vision to manage local songs hands-free. Built with **Python, OpenCV, MediaPipe, and Pygame**, it enables real-time control of playback, volume, and navigation through intuitive hand gestures with a smooth, modern, and lag-free interface.

This repository is a part of my Data Analyst/Data Scientist portfolio. It demonstrates my ability to handle complex data, build robust models, and derive actionable insights.

## Features
- End-to-end data processing pipeline
- Exploratory Data Analysis (EDA)
- Robust modeling and predictive analytics
